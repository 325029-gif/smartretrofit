# SmartRetrofit

**Not just monitoring the machine — learning the machine.**

A professional product site for RetroFit Solutions: a low-cost, plug-and-play IoT retrofit that gives existing MSME machines real-time monitoring, Machine DNA, and predictive maintenance alerts — without replacing a ₹30–50 lakh asset.

Built for an IIT Bombay / SIH 2025 Hardware (Smart Automation) walkthrough. Problem statement **SIH26219**.

## What this site includes

- Editorial product site (problem, solution, architecture, impact, team, contact)
- Interactive **3D model** of the SR-32 edge unit (orbit, exploded view, status LED)
- **Live command centre** — simulated six-machine MSME cell with telemetry, Machine DNA, health scores, and an alert desk
- Pitch controls: inject bearing wear, overheating, current spike, or voltage sag and watch a structured alert fire

## How to walk the pitch

1. Open the home page and orbit the device.
2. Open **Product** → Exploded view to show ESP32 + sensor modules.
3. Open **Live demo** → select a lathe → **Bearing wear**.
4. After a few samples, Machine DNA raises an alert with a recommended action. Acknowledge it.
5. Reset the fleet before the next judge.

The command centre is a high-fidelity simulation in the browser (no shop-floor hardware required for the pitch).
